# Миграция v3 → v4 и откат

## Принципы

- **v3 не изменяется и не удаляется**: миграция читает каталог v3 (read-only).
- v4 живёт в отдельном каталоге (`~/projects/tubecook_v4`) со своей БД
  `data/tubecook.db`, своими артефактами `data/jobs/<id>/`.
- Откат = остановить v4; v3 продолжает работать, как раньше. Никаких общих
  состояний.

## Перенос данных

```bash
python -m tubecook.cli import-v3 ~/projects/tubecook
```

- `jobs/*.json` v3 → задания v4 (state=queued) с `meta.origin="v3"`.
- Сохраняются: тема (title), хук, сценарий, теги, визуальные подсказки сцен.
- **Важно**: в манифестах v3 не было первоисточников и атрибутов фактов —
  протокол v4 их требует. Импортированные задания получают пометку «требует
  дооформления» и НЕ пойдут в автопубликацию до обновления по протоколу
  (Саша присылает полноценное задание с тем же URL → `/allow-update`).
- BGM `assets/bgm/soft_loop.mp3` уже скопирован в v4 (royalty-free из v3;
  подтверждение права использования — за владельцем, см. docs/OPERATIONS.md).
- `build/` v3 не переносится: артефакты пересоздаются рендером v4.

## Отличия v3 → v4 (для оператора)

| Аспект | v3 | v4 |
|---|---|---|
| Оркестрация | Go-бот + shell-скрипты | единый Python-сервис (потоки) |
| Очередь | JSON-файлы, статусы в файле | SQLite: транзакции, lease, retry, аудит |
| Протокол заданий | `#TUBECOOK_JOB` (базовый) | v4: + checked_at, атрибуция фактов, multipart, ACK-квитанции, дедуп, конфликты |
| Расписание | timer 1 раз в 6 ч | слоты 00/06/12/18 Kyiv, DST, catch-up, TTL |
| Рендер | Ken-Burns + красный штамп + `-shortest` (баг обрыва) | смысловые сцены + движение + `tpad`-хвост, `-shortest` запрещён |
| Субтитры | караоке v3 | караоке v4 (читаемость, безопасные отступы) |
| Публикация | скрипты по флагам | dry-run по умолчанию, per-target, uncertain, верификация |
| Проверки | exit code | 81 автотест + ffprobe-проверки длительностей |

## Rollback-процедура

```bash
systemctl --user stop tubecook-v4.timer tubecook-v4.service 2>/dev/null
# v3 продолжает работать; при желании включить его юниты обратно
```
Данные v4 остаются в `tubecook_v4/data/` для разбора (не влияют на v3).
