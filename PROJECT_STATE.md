## 2. Что реализовано (архитектура v4, с нуля, Python 3.10+)

- Единый пакет `tubecook` вместо Go+скрипты: транспорт-агностик бот-ядро
  (консоль + опциональный aiogram), очередь на SQLite (WAL, транзакции, lease,
  retry/backoff, recovery), планировщик Europe/Kyiv (слоты 00/06/12/18,
  DST через zoneinfo, catch-up ≤1, TTL свежести 36 ч, уведомление о пустом слоте).
- Протокол `#TUBECOOK_JOB v4` (текст + JSON, multipart PART n/m, валидатор,
  content-hash, дедуп по каноническому URL, конфликт-ID без перезаписи,
  `/allow-update` для осознанного обновления новости).
- Безопасность: роли по Telegram ID; PRIORITY/AUTO_PUBLISH из тела — данные;
  инструкции в сценарии — контент; команды только админу.
- Рендер: сцены по смыслу фраз (hook/stat/compare/quote/fact/outro) из
  фактических таймингов WordBoundary; процедурная графика (Pillow) +
  движение FFmpeg (zoompan фона, ease-out въезд карточки, параллакс-слой,
  xfade, fade). Аудио: даккинг BGM sidechaincompress, двухпроходный loudnorm
  R128 (-16 LUFS), фейд. **-shortest запрещён** (assert в коде + тест);
  хвост = tpad=clone 0.9 c; длительности проверяются ffprobe после кодирования.
- Доставка: мастер 1080x1920@30; Telegram 540x960 faststart ≤15 МБ
  (CRF-ladder 23→26→28, длительности сохраняются, тест).
- Публикация: dry-run по умолчанию (outbox, «это НЕ публикация»), per-target
  статусы, uncertain при таймауте (без слепого повтора, /check + verify для
  YouTube через videos.list), частичные сбои ретраятся только на упавшей площадке.
- Миграция v3: `python -m tubecook.cli import-v3 <путь к v3>` (read-only,
  v3-задания без источников помечаются как требующие дооформления).
- VA-API: авто-включение при наличии /dev/dri/renderD128 (h264_vaapi+hwupload),
  иначе CPU libx264 veryfast. Замеры на HP — скрипт `scripts/hp_bench.sh`
  (в песочнице VA-API физически отсутствует — честно отмечено).

## 5. Известные ограничения / решения

- Рендер в песочнице был медленным из-за 2 ядер: двухстадийная схема
  (сцены по одной → сборка) съедает <1 ГБ RAM — важно для HP с 12 ГБ.
  На HP ожидается 38–180 c на выпуск (по матрице v3 для похожего графа).
- edge-tts — неофициальный сервис Microsoft: для регулярного продакшена
  оценить Azure Speech F0 (0.5M симв./мес) или локальный Piper (MIT) —
  адаптер TTS сменный (`tubecook/media/tts.py`, движок указывается в отчёте).
- Quota YouTube videos.insert: не полагаться на старую цифру «1600 units»;
  см. docs/CLOUD_RESEARCH.md (проверять в Cloud Console свой проект).
- Стоковые видео-клипы: интерфейс сцен готов (`visual_plan`), адаптер
  Pexels/Wikimedia из v3 не переносился как есть; при подключении заполнять
  метаданные лицензий (assets-таблица).
